How to Export Your SYSTEM Hive File

  1. Open PowerShell as Administrator (right-click the Start menu or PowerShell icon and select "Run as Administrator")
  2. Run this command:
    3. reg save HKLM\SYSTEM C:\Users\%USERNAME%\system_test.hive
  3. This creates a file at C:\Users\<YourName>\system_test.hive - open File Explorer, go to that location, and upload the file here.

Replace <YourName> with your actual Windows username, or just navigate to your Users folder in File Explorer to find it.

Administrator access is required to export this file. This only reads a copy of the registry and does not modify your system.

How to Export the Device Configuration Log

  1. Press Win+R, type eventvwr.msc, press Enter
  2. In the left panel, navigate to: Applications and Services Logs > Microsoft > Windows > Kernel-PnP > Device Configuration
  3. Right-click "Device Configuration" and select "Save All Events As..."
  4. Save the file as device_config_events.evtx and upload it here

This log records device driver installation/configuration events, useful for identifying first-time USB connections.

How to Export the Device Management Log

  1. Press Win+R, type eventvwr.msc, press Enter
  2. In the left panel, navigate to: Applications and Services Logs > Microsoft > Windows > Kernel-PnP > Device Management
  3. Right-click "Device Management" and select "Save All Events As..."
  4. Save the file as device_management_events.evtx and upload it here

This log reliably records every USB connect/disconnect event, including repeated connections of the same device - use this for accurate real-time timeline data.
