## Data Flow

1. **Upload & Ingestion:** User uploads Windows Registry Hive (`SYSTEM`) or Event Log (`.evtx`) through `/usb-forensic`.
2. **Parsing & Extraction:** `regripper_runner` / `usbstor_parser` extracts USB device metadata; `event_parser` extracts event logs.
3. **Correlation & Analysis:** `session_correlator` matches device IDs across sources, builds timelines, and calculates risk scores via `analytics_service`.
4. **Persistence:** Device metadata and audit attempts are stored in `usb_forensics.db`.
5. **Presentation & Export:** Analyzed sessions display on `dashboard.html` / `usb_forensic.html`, with optional PDF report generation via `report_generator.py`.
